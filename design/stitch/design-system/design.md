# Jill Design System

The design system is engineered for high-stakes enterprise environments, focusing on precision, clarity, and AI-assisted intelligence. The brand personality is "The Expert Partner" - authoritative yet accessible, providing deep insights through a filtered, focused lens.

The visual style is a refined Corporate Modern approach optimized for dark environments. It uses data-first hierarchy, medium-high density, tonal layering, and subtle micro-grid texture in header backgrounds.

## Layout

- 12-column fluid grid
- 16px gutters
- 240px desktop sidebar
- 64px top bar
- 20px card padding
- Mobile under 768px: one-column stack and collapsed sidebar
- Tablet 768px to 1200px: icon rail
- Desktop above 1200px: full sidebar

## Components

- Primary buttons: solid `#29B6F6` with dark navy text
- Secondary buttons: 1px cyan outline
- Cards: `#12314E`, 8px radius, 1px `#1E4369` border
- Inputs: `#081B2E` with subtle border and cyan focus glow
- Navigation active state: cyan text and vertical cyan line
- Tables: horizontal row borders only, section-label headers
- Metric accents: large numbers with trend indicator
